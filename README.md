# 📊 Data Analysis and Preprocessing Project

## 📌 Overview

This project demonstrates fundamental data science tasks including data cleaning, preprocessing, exploratory data analysis (EDA), and text data analysis using Python.

It covers both structured and unstructured datasets to build a strong foundation in data analysis.

---

## 🛠️ Tech Stack

* Python
* Pandas
* NumPy
* Matplotlib

---

## 📂 Datasets Used

* Iris Dataset
* Student Dataset
* Sample Text File

---

## 🔍 Key Tasks Performed

### 1️⃣ Dataset Exploration

* Loaded datasets using Pandas
* Displayed first and last records
* Checked shape, columns, and data types
* Generated descriptive statistics

---

### 2️⃣ Column Classification

* Identified:

  * Numerical columns
  * Categorical columns
  * Ordinal columns
* Used Pandas functions like `select_dtypes()`

---

### 3️⃣ Structured & Unstructured Data Analysis

* Analyzed structured dataset using statistical methods
* Processed text data:

  * Converted text to lowercase
  * Removed punctuation
  * Calculated word frequency using `Counter`

---

### 4️⃣ Data Cleaning & Preprocessing

* Handled missing values
* Dropped null values
* Filled missing values using mean
* Cleaned real-world dataset (Toyota dataset)

---

## 📊 Results & Insights

* Successfully performed EDA on multiple datasets
* Extracted meaningful insights from structured data
* Generated word frequency analysis for text data
* Improved dataset quality using preprocessing techniques
